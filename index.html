Code Google Apps Script (Mis à jour)

⚠️ Procédure essentielle pour Google Apps Script :

  1. Ouvrez votre projet Google Apps Script.
  2. Collez l'intégralité du code ci-dessous et enregistrez (CTRL + S).
  3. Cliquez sur Déployer > Gérer les déploiements.
  4. Cliquez sur le crayon (Modifier), choisissez Version : "Nouvelle version".
  5. Vérifiez que "Exécuter en tant que" = "Moi" et "Qui a accès" = "N'importe qui" (Anyone).
  6. Cliquez sur Déployer et copiez l'URL fournie.
