Code Google Apps Script (pour liaison directe)

  1. Ouvrez votre fichier Google Sheets.
  2. Allez dans le menu Extensions > Apps Script.
  3. Remplacez tout le contenu par le script ci-dessous et enregistrez (CTRL+S).
  4. Cliquez sur Déployer > Nouveau déploiement, choisissez Application Web.
  5. Définissez "Qui a accès" sur "N'importe qui" (Anyone), puis validez.
